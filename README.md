# 🗓️ 段考時程表 Pro (v.5.2 Cloud Sync)

這是一個純網頁版（Standalone HTML）的段考時程管理工具。原先基於 Google Apps Script (GAS) 構建，現已完全轉化為本機執行版本，具備離線使用、瀏覽器快取存檔與雲端同步功能。

![版本](https://img.shields.io/badge/Version-5.2-orange)
![技術](https://img.shields.io/badge/Tech-HTML5_/_CSS3_/_JS-blue)

## ✨ 特色功能

- **🚀 免後端執行**：純 HTML/JS 驅動，不需伺服器，下載後點擊 `index.html` 即可在瀏覽器開啟。
- **💾 瀏覽器即時存檔**：採用 `localStorage` 技術，所有的科目、時間、小工具設定都會即時儲存在您的瀏覽器中，重新整理也不會消失。
- **📥 匯出與匯入備份**：支援將所有資料（包含 1~3 天的所有設定）匯出為 `.json` 備份檔，方便跨裝置搬移或保存。
- **🧩 多樣化小工具**：
  - **數位時鐘**：白底與駭客風格兩款。
  - **指針時鐘**：直觀的模擬時鐘。
  - **公告欄與便利貼**：可自由縮放文字與編輯內容。
  - **🚥 紅綠燈**：課堂管理的視覺化工具。
  - **🎲 隨機抽籤**：快速抽取學生號碼。
- **🎨 自由配色**：支援自定義面板背景（純色、漸層、黑板、夜間模式）。
- **🔋 動態能量條**：科目時間會根據目前系統時間自動顯示剩餘百分比。

## 🛠️ 如何使用

1.  **開啟程式**：直接使用 Chrome, Edge 或 Firefox 開啟 `index.html`。
2.  **編輯內容**：點擊「+新增」增加科目，直接在表格內輸入名稱與時間。
3.  **切換天數**：底部標籤可切換第一、二、三天，系統會自動保存每一天的獨立配置。
4.  **複製天數**：可點擊「📥複製第1天」將第一天的背景與科目快速帶到其他天數。
5.  **備份資料**：建議定期使用底部的「📤匯出」功能下載備份檔，以防瀏覽器快取被清理。

## ⚙️ 技術說明

- **資料存儲**：JSON 字串序列化存入 `localStorage`。
- **即時同步**：具有 Debounce (1s) 的 `input` 事件監聽，達成輸入即存檔的體驗。
- **Google 登入**：目前保留了 Google Identity Services 的接入介面模板，若需正式啟用，請在原始碼中填入您的 `Client ID` 並於 Web Server 環境下執行。
